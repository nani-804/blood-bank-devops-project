# Blood Bank DevOps Project

This project demonstrates deployment of a Blood Bank Application using AWS and DevOps tools.

## Architecture
- AWS VPC
- Public & Private Subnets
- EC2 Instances
- RDS MySQL
- Load Balancer
- Auto Scaling Group

## DevOps Tools Used
- Git & GitHub
- Jenkins
- Docker
- Kubernetes
- Terraform

## Features
- 3-Tier Architecture
- CI/CD Pipeline
- Dockerized Application
- Infrastructure as Code
- Load Balancing
- Auto Scaling
